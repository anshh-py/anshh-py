### 📄 [PageGlance](https://github.com/anshh-py/PageGlance)

**Context-Aware Web Page Question Answering with RAG**

<img src="https://img.shields.io/badge/RAG-00A896?style=flat-square&labelColor=0d1117" />
<img src="https://img.shields.io/badge/Embeddings-7B2FBE?style=flat-square&labelColor=0d1117" />
<img src="https://img.shields.io/badge/Chrome%20Extension-4285F4?style=flat-square&labelColor=0d1117" />

A Chrome extension that lets users ask questions about web pages and receive answers grounded in the page's extracted content.

| Component | Implementation |
|---|---|
| Retrieval | Semantic search over embedded page content |
| Embeddings | all-MiniLM-L6-v2 |
| Generation | Context-grounded LLM responses |
| Citations | Source-aware answer references |
| Backend | Python · PostgreSQL · Neon |

**Focus:** Building practical retrieval systems with contextual accuracy and traceable answers.

[Explore Repository →](https://github.com/anshh-py/PageGlance)
